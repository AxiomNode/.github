# Maintaining this repository

This repository only holds organization-level public profile content; it is not part of the runtime or deployment chain.

- `README.md` is the public organization overview shown on the repository page; `profile/README.md` is the same content rendered on the organization page. Keep them identical.
- `.github/portfolio/` holds portfolio assets (icon, banner, metadata).
- Keep the content consistent with the current repository map and descriptions. Architecture truth is owned by the central `docs` repository.
- Do not mention or link private repositories, and avoid internal operational detail.
- Public copy is technical English.
- Publishing guide: `docs/guides/capabilities/platform/organization-profile-publishing.md` in the `docs` repository.
